- Evidence Role: bounded architecture discovery and an exact failed authoring preflight, not a canonical Form Profile schema or an implementation acceptance.
- Review Context: requested by Sigma as a scalable, `.transitions`-like discovery/embedding model while keeping Native schema directories flat and avoiding the older `.transitions.js` presentation-source overlap.

## Evidence Material

- Material Kind: source-contract comparison, non-mutating authoring failure, and experimental form-surface example.
- Material: [Exact example (not a qualified artifact)](fixtures/evidence-image-surface.experimental.md). - Known Losses: no cold host presentation of a form profile and no qualified active `.forms` discovery; no full Native/Core test suite was run as part of this bounded read-only investigation.

## Interpretation Limits
