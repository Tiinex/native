## Transfers

- sigma-acceptance
  - Transfer Kind: work-and-responsibility
  - Description: One installed Windows acceptance pass against the exact carried Reduction and Guided Handoff candidate. Confirm Reduction appears in Core-qualified New Artifact, that the choice None / This Workspace / Multi-workspace precedes the form, and that previously deleted trace artifacts yield terminal leaves only with historical v2 labels while preserved siblings do not. Confirm Guided Handoff explicitly selects Entry/Target, that clipboard matches read-only preview and no automatic transport window opens when packaging completes. Observe qualifier latency only as a remaining measurable UX condition.
  - Controlling Artifact: [Anchor bounded integration evidence](../work/reduction-mvp/005-anchor-reduction-final-local-integration-evidence.trace.md)
  - Boundary: Sigma evaluates an installed Windows candidate and reports PASS, PASS WITH OBSERVATIONS or BLOCK. No authority to clean real artifact history, perform remote write, publish to Marketplace, close unrelated Tasks or treat synthetic historical GitHub links as verified bytes is transferred.
